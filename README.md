# YadroProject
Для решения задачи необходимо было реализовать алгоритм сортировки массива во внешней памяти. Так как не было дано ограничения на M, то я вынес этот параметр в config.
Так как записывать и читать можно только одно число с ленты на позиции, на которой находится головка, то я использовал 4 временных файла для сортировки слиянием. Для начала сортирую блоки размера M, а затем чётные отправляю в первый файл, нечётные во второй. Затем слияние двух последовательных блоков и запись чётных в третий, нечётных в четвёртый, аналогично процесс повторяется, пока не получится один блок, он уже переписывается в ответ.
Асимптотика алгоритма $O(N \log_2 (N / M))$, так как вычисления в оперативной памяти считаем быстрыми, а во внешней памяти у нас $N / M$ блоков, которые мы сливаем по два, значит количество таких итераций $O(\log_2 (N / M))$, элементов $N$
